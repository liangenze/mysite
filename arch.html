5权限规则引擎

数据维度 + API维度，双重权限控制
数据维度权限
应用层鉴权
场景：学生查看本院成绩排名
判定：无权限
原因：学生只能查本人数据，不能查院级排名
场景：学生查看本人成绩
判定：有权限
代码层鉴权
-- 权限占位符匹配
SELECT * FROM score
WHERE student_id = :user_id -- 当前登录用户
AND class_id = (
  SELECT class_id FROM student
  WHERE student_id = :user_id
)
API 维度权限
API 鉴权示例
场景：A班老师导出B班成绩单
判定：无权限
原因：API 鉴权校验班级归属
场景：A班老师导出A班成绩单
判定：有权限
常规鉴权措施
措施说明
敏感数据脱敏身份证号、手机号中间四位 * 号
